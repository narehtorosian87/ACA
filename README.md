# ACA

Nareh's workspace for the ACA course — a place to build and organize projects, custom Claude Code skills, and finished products while learning Claude Code as a product manager.

## Structure

- `projects/` — work-in-progress exercises and course projects. Give each project its own subfolder.
- `products/` — finished, shareable outputs (documents, artifacts, decks, specs) produced from the projects.
- `.claude/skills/` — custom Claude Code skills built during the course. `.claude/skills/example-skill/` shows the minimal shape of a skill (a `SKILL.md` with frontmatter and instructions).

## Getting started

Ask Claude Code to create a new project folder under `projects/` for each course exercise, and to save finished deliverables under `products/`. When the course covers building a custom skill, add it under `.claude/skills/<skill-name>/SKILL.md` following the pattern in `example-skill/`.
