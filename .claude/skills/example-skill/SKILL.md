# Example Skill

This is a placeholder skill that demonstrates the minimal shape Claude Code expects:

1. A `SKILL.md` file inside `.claude/skills/<skill-name>/`.
2. YAML frontmatter with a `name` and a `description` — the description is what Claude uses to decide when to trigger the skill, so make it specific about what the skill does and when to use it.
3. Instructions below the frontmatter describing what Claude should do when the skill is invoked.

Replace this content when you build your first real skill during the course.
