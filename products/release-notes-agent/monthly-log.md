# Release Notes Monthly — Log

Dedupe/history log for the `release-notes-monthly` agent (`.claude/skills/release-notes-monthly/`). Every Asana ticket (tagged "Release Note") that has been reviewed by the agent gets one line here, so it's never re-processed. Most recent run first.

Format per run:

```
## YYYY-MM-DD — release notes for {Month Year}

**Included in email:**
- [Ticket name](permalink) — ticket gid

**No change shipped (excluded):**
- [Ticket name](permalink) — ticket gid — reason
```
